# Doda Fetch (CLI Downloader)

Doda Fetch is a lightweight command-line downloader utility. It serves as a classic alternative to `wget` or `curl`, featuring a nostalgic ASCII progress bar that renders dynamically as files download.

## How to Use

Provide the URL of the file to download. Optionally, provide a second argument for the local output filename.

```bash
python doda_fetch.py http://example.com/file.zip output.zip
```
