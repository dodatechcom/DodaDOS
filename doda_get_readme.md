# Doda Get (CLI Package Manager)

Doda Get is a text-mode package manager and software catalog for the Doda DOS ecosystem. It provides a visual `curses` interface to browse available scripts, games, and utilities from a remote repository, allowing users to "install" (download) them directly to their local environment with a single keystroke.

## How to Use

Simply execute the script to open the interactive catalog:
```bash
python doda_get.py
```

## Shortcut Keys

| Key             | Action                  |
| --------------- | ----------------------- |
| **Arrow Keys**  | Navigate the list of available packages. |
| **ENTER**       | Install the selected package. |
| **Q, F10**      | Exit the package manager. |
